## 📖 Sobre el repositorio

Este repositorio es mi **gimnasio de programación en Java** 💪: aquí practico los fundamentos de la **Programación Orientada a Objetos (POO)** y temas más avanzados del lenguaje mediante mini-sistemas reales como nóminas, tiendas, bibliotecas y máquinas expendedoras.

El repositorio se divide en dos grandes bloques:

| Carpeta | Contenido |
|---|---|
| 📚 [`Clases/`](./Clases) | Fundamentos de POO: clases, objetos, encapsulamiento, herencia y polimorfismo |
| 🎓 [`TemasAvanzados/`](./TemasAvanzados) | Colecciones, excepciones, interfaces, clases abstractas, varargs y serialización |

---

## 📚 Clases — Fundamentos de POO

> Mini-sistemas de negocio para dominar la base de la orientación a objetos.

### 🐾 Animales
Práctica de **herencia y polimorfismo** con una clase base `Animal` y sus subclases `Perro` y `Gato`.

### 🔢 Aritmética
Clases básicas (`Aritmetica`, `Rectangulo`, `CuentaBancaria`) con sus pruebas; práctica de **métodos, atributos y encapsulamiento**.

### 📖 Librería
Mini sistema de biblioteca con `Libro`, `Prestamo` y su prueba; práctica de **relaciones entre objetos**.

### 🧠 Lógica
Colección de **+12 ejercicios de lógica de programación**: arrays, `Scanner`, promedios de ventas/inventarios, condicionales y bucles.

### 💰 Nómina
Sistema de nómina con clase abstracta `Empleado` y subclases `EmpleadoAsalariado` / `EmpleadoPorHoras`; práctica de **herencia y sobrescritura de métodos**.

### 📢 Notificaciones
**Polimorfismo** con clase base `Mensaje` y subclases `Email` y `Whatsapp` para enviar notificaciones.

### 💳 Pagos
Sistema de cobro con clase base `MetodoPago` y subclases `TarjetaDebito` / `TransferenciaQr`; **polimorfismo aplicado a pagos**.

### 👤 Persona
Clase `Persona` con constructores, getters/setters y uso de `this`; el **"Hola Mundo" de la POO**.

### 🛠️ Prácticas
Ejercicios varios: tienda de computadoras, cuenta bancaria y persona ejecutable; refuerza **composición y encapsulamiento**.

### 🚗 Renta Car
Sistema de alquiler de vehículos: `GestorAlquiler` con la jerarquía `Vehiculo` → `AutoPasajero` / `CamionCarga`; práctica de **herencia**.

### 📺 Suscripción
Sistema de streaming con `Subscription` y planes `PlanFamiliar` / `PlanEstudiante`; **herencia y cálculo de precios**.

### 🛒 Ventas
Sistema de ventas con `Producto`, `Orden` e impresión de recibos; práctica de **composición de objetos**.

## 🎓 Temas Avanzados

> Profundizando en las herramientas poderosas del lenguaje.

### ⚙️ Archivos individuales

| Archivo | Concepto |
|---|---|
| `ArgumentosVariables.java` | Varargs (`tipo... parametro`) |
| `ClaseAbstracta.java` | Clases abstractas: `FiguraGeometrica` → `Rectangulo` / `Circulo` |
| `Excepciones.java` | Manejo básico con `try/catch/finally` |
| `ForEach.java` | Recorrido de colecciones y arreglos |
| `JavaBeans.java` | Patrón JavaBean: clase serializable con getters/setters |
| `Mapa.java` | Interfaz `Map` (HashMap): pares clave-valor |
| `Sets.java` | Interfaz `Set` (HashSet): colecciones sin duplicados |
| `Traductor.java` | Interfaces implementadas por `Ingles` y `Frances` |

### 📦 Proyectos

### 🍸 Bar
Validación de edad para entrar a un bar lanzando `RuntimeException`; **excepciones no verificadas**.

Excepciones verificadas con `throws`: división segura y captura de errores.

### 📋 Listas
Uso de la interfaz `List` (ArrayList) y todas sus operaciones.

### 🍿 Máquina de Snacks
Máquina expendedora con `Snack` (serializable), catálogo estático y lógica de compra.
